# Contributing

Issues and pull requests are welcome. The bar for contributions:

- **One job per skill.** A skill teaches an agent one social media job, end to end.
- **Keep the format.** Frontmatter (name, description with TRIGGERS, category, version), then Inputs, Workflow, Output Format, Success Metrics, Guardrails, Quality Checklist and a fictional Example.
- **Keep the guardrails.** No engagement pods, fake followers, spam automation or undisclosed sponsorship tactics — skills that teach them will not be merged.
- **Fictional examples only.** No real client names, private messages or unverifiable results.
- **Run the validator.** `python3 tools/validate.py` must pass: 100% frontmatter compliance and catalog.json matching the folders.
